## 📖 模组简介

本模组为 Minecraft 1.21.11 开发，旨在**不破坏原版体验的前提下**，通过床铺、钓鱼、末影箱、自定义方块等原版机制，打造一套完整的群组/单服积分经济与互动娱乐体系。

所有数据落盘于服务端存档的 `world/jifenyouxi.db`（SQLite），支持事务操作与并发安全。

---

## 🎮 核心玩法与特性

1. **床铺签到**：
   - 玩家入睡起床后自动根据 MC 游戏日判定签到。
   - 每日首次奖励 1~10 积分，连续签到 7 天额外奖励 20 积分。

2. **原版钓鱼扩展**：
   - 根据所处群系（深海、丛林）及昼夜时段概率钓起特产鱼获（如远古利维坦幻影、暗月幽灵鱼、祥瑞锦鲤王等）。
   - 手持鱼获右键即可直接出售换取积分，钓获/售出稀有鱼全服广播。

3. **末影箱银行**：
   - 存放金锭即为存款（1金锭 = 10积分）。
   - 每日凌晨自动享受 5% 活期利息，利息以金锭形式直接注入末影箱。

4. **幸运赌桌方块**：
   - 放置并右键【幸运赌桌】方块，打开原生 3×9 互动界面。
   - 包含：幸运大转盘、疯狂水果机、极速刮刮乐、神秘抽卡。

5. **告示牌全服排行榜**：
   - 在出生点附近放置第一行含有 `[积分榜]` 的告示牌。
   - 模组每 5 分钟自动扫描并刷新全服积分 Top10 榜单。

6. **每日出生点宝箱**：
   - 每个游戏日清晨在出生点正上方刷新一个宝箱。
   - 当天首位开启的玩家获得 150~300 积分及附魔金苹果/下界合金锭/SSR 卡牌大奖。

7. **抽卡台方块**：
   - 自定义抽卡机台方块，右键消耗 10 积分抽取卡牌（SSR/SR/R/N）。
   - 抽到 SSR 触发不死图腾粒子与全服喜报，多余卡牌可右键分解回收积分。

8. **智慧谜题方块**：
   - 世界中生成的谜题方块，右键出题（速算、成语、历史、常识）。
   - 60秒内直接在聊天栏输入答案，答对爆金币，答错方块自毁。

9. **银行柜台与征信借贷**：
   - 放置并右键【银行柜台】方块打开金融中心，可申请应急贷款（100/500/1000）。
   - 逾期未还将全服广播催收，且后续任何积分收入将被强制优先抵扣还款。

## 🛠️ 构建与安装

### 环境要求
- JDK 21 或更高版本
- Minecraft 1.21.11
- Fabric Loader >= 0.19.0
- Fabric API >= 0.141.6+1.21.11

### 构建命令
```bash
./gradlew build
```
编译产物位于 `build/libs/jifenyouxi-1.0.0.jar`，直接放入服务端 `mods/` 文件夹即可。
